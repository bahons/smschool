# 🏫 Smart School: AI Демо және Тестілеу Жүйесі

Бұл жүйе мектептердегі бейнебақылау камералары арқылы оқушылар арасындағы төбелес пен агрессивті қақтығыстарды (bullying & fights) нақты уақытта биомеханикалық әдіспен анықтауға арналған.

---

## 🎯 Негізгі ерекшеліктері

1. **Биомеханика және Қаңқа моделі (YOLOv8-pose)**:
   - 17 COCO анатомиялық нүктелері арқылы адам денесінің қимылын анықтайды.
   - **Бет-әлпетті тану жоқ**, жеке өмірге қол сұғылмайды.
   - `--blur-head` режимі бас аймағын (0-4 нүктелер) бұлдырлап, толық құпиялылықты сақтайды.
2. **Conflict Index алгоритмі**:
   - 9 және 10 нүктелердің (білектер: left & right wrists) үдеуі мен жылдамдығын есептейді.
   - Адамдардың бір-біріне жақындасу дәрежесін (interpersonal distance proximity) бағалайды.
   - Temporal exponential smoothing арқылы кездейсоқ шуды басады.
   - **2 секундтық тұрақты қауіп фильтрі**: Жалған дабылдарды (қол сермеу, жүгіру, амандасу) жоққа шығарады.
3. **Презентацияға дайын материалдар**:
   - `outputs/comparison.png`: Екі жағдайды (Тыныш сынып vs Төбелес) қатар салыстыратын таза инфографика.
   - `outputs/presentation_assets/SmartSchool_Presentation.pptx`: 6 слайдтық авто-генерацияланған презентация.
   - `outputs/presentation_assets/conflict_alert_moment.gif`: Төбелес сәтінің 6 секундтық шағын GIF-і.
   - `outputs/telegram_alert_mockup.png`: Telegram ботының дабыл хабарламасы макеті.
4. **Сапаны объективті бағалау**:
   - `data/labels.csv` арқылы нақты уақыттар белгіленсе, `evaluation.md` автоматты есептеледі.
   - Егер белгіленбесе, **ешқандай сандар ойдан шығарылмайды**.

## 🚀 Іске қосу нұсқаулығы

### 1. Толық демо пайплайнын іске қосу
Екі видеоны да өңдеп, барлық графикті, салыстыруды және есептерді дайындау:
```bash
python run_demo.py
```

Құпиялылықты сақтау үшін бас аймағын бұлдырлаумен іске қосу:
```bash
python run_demo.py --blur-head
```

Нақты Telegram-ға хабарлама жіберу (`config.yaml`-да bot_token толтырылған болса):
```bash
python run_demo.py --send-telegram
```

---

### 2. Интерактивті веб-панель (Streamlit)
Презентация кезінде қазылар алқасына тікелей көрсету:
```bash
streamlit run demo_app.py
```

---

### 3. Шектерді калибрлеу (Threshold Calibration)
Екі бейне бойынша индекстердің статистикалық үлестірімін (min, mean, 95th percentile, max) талдап, оңтайлы шектерді таңдау:
```bash
python scripts/calibrate.py
```
> **Шектердің таңдалу логикасы:**
> - `ЕСКЕРТУ (0.40)`: Тыныш сыныптағы оқушылардың 95-процентильдік қозғалыс шегінен жоғары етіп қойылған.
> - `ҚАУІП (0.65)`: Оқушылар бір-біріне жақын келіп, білектерімен жылдам сермеу әрекеті жасалғанда ғана жетілетін деңгей. Бұл деңгей тыныш сыныптың ең жоғарғы мәнінен едәуір алыс.

---

### 4. Сапа бағалау (Evaluation)
Метрикаларды тексеру:
```bash
python scripts/evaluate.py
```
`data/labels.csv` файлына төбелестің басталған және аяқталған секундтарын енгізуге болады:
```csv
video,start_sec,end_sec,label
video1.mp4,3.2,9.5,conflict
```

## 🌐 5. Веб-сайт және REST API (FastAPI + HTML/CSS/JS)

Жүйеге кез келген браузер арқылы жаңа видео жүктеп, оны онлайн талдауға арналған жеңіл әрі заманауи веб-сайт пен REST API қосылды.

### Іске қосу:
```bash
start_web.bat
# немесе
python start_server.py
```

- **Веб-интерфейс**: [http://localhost:8000](http://localhost:8000)
  - 🎥 **Drag & Drop видео жүктеу** (MP4, AVI, MOV);
  - 🔒 **Жеке құпиялылық режимі** (`--blur-head`) қосқышы;
  - ⚡ **1 басу арқылы дайын демо нәтижелерді көру** (Тыныш сынып vs Төбелес);
  - 📊 Өңделген бейне, Conflict Index графигі және метрикаларды бір экранда көрсету.
- **Интерактивті Swagger API құжаттамасы**: [http://localhost:8000/docs](http://localhost:8000/docs)
  - `POST /api/upload`: видео жүктеп, JSON есеп алу;
  - `GET /api/demos`: дайын нәтижелер тізімі;
  - `GET /outputs/{task_id}/annotated.mp4`: өңделген видео ағыны.

1. **Видео ашылмаса (`Could not open video stream`)**:
   - `data/videos/video1.mp4` немесе `data/videos/video2.mp4` файлының орнында бар-жоғын тексеріңіз.
   - `config.yaml` файлындағы `path` жолдарының дұрыстығына көз жеткізіңіз.
2. **OpenCV VideoWriter кодек қатесі (`mp4v` / `avc1`)**:
   - Windows жүйесінде әдепкі `mp4v` FourCC қолданылады. Егер видео сақталмаса, жүйеңізде K-Lite немесе Windows Media Codec бар екенін тексеріңіз.
3. **Шрифт немесе Кириллица әріптері дұрыс шықпаса**:
   - Жүйе автоматты түрде Windows стандартты `C:\Windows\Fonts\arial.ttf` немесе `tahoma.ttf` шрифттерін пайдаланып, «ҚАУІП: ТӨБЕЛЕС», «НОРМА» сөздерін қазақша анық шығарады.
